# Portal de Performance — Duosfera Digital

Portal interno da equipe Duosfera. Publicado pelo GitHub Pages a partir da pasta `docs/`.

Todo o conteúdo é **criptografado** (AES-GCM, chave derivada da senha com PBKDF2-SHA256).
O que está neste repositório é só texto embaralhado: sem a senha, nenhum relatório pode ser lido.

As páginas são geradas automaticamente. Não editar os arquivos à mão.
